# BaKo für Claude

Offizielles Claude-Plugin von BaKo (https://bako.co.at): Konnektor `https://bako.co.at/mcp` und Arbeitsanleitung. Installation in Claude Code: `/plugin marketplace add <dieses Repository>`, dann `/plugin install bako@bako`. In claude.ai und Cowork: Customize → Plugins → Add marketplace. Details im Ordner `bako/` und unter https://bako.co.at/ki-assistenten.

Official Claude plugin for BaKo, a construction-site coordination platform. See `bako/README.md`.
